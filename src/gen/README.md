# `src/gen/` — generated + hand-written twin code

| File | Origin | Committed? |
|---|---|---|
| `revs_gen.c` | generated by `make gen` | no (git-ignored) |
| `revs_decl.h` | generated by `make gen` | no |
| `mem.h` | generated by `make gen` from `symbols.csv` var rows | no |
| `revs_validate_list.h` | generated by `make gen` — the `VALIDATE_FUNCS` names the harness checks for fixture-or-fail | no |
| `revs_manual.c` | **hand-written** — stubs for self-modifying routines the transpiler cannot represent | yes |
| `revs_native.c` | **hand-written** — faithful native twins, `make validate`d, linked into both backends | yes |

⚠ Never edit `revs_gen.c` / `revs_decl.h` / `mem.h` by hand — they are overwritten on every
`make gen`. Names come from `disasm/symbols.csv`; see `docs/transpiler.md`.

Which side of the seam a twin belongs on: `docs/faithfulness-seam.md`.
